# 🛏️ 2024 문화체육관광 데이터 활용 대회 
- 주제 : 데이터 분석을 통한 문화체육관광 이슈와 정책 효과 분석 및 활용
- 주관 : 한국문화관광연구원 / 협찬 : 신한카드
<br/>

## 📁 프로젝트 개요
- 기획 및 분석 : 서재우, 임정민
- 프로젝트 기간 : 2024.11.18. - 2024.11.25.
- 프로젝트 명 : 지역간 그린스테이 양극화 해소를 위한 그린스코어 기반 호텔 선정 및 유치 전략
<br/>

## 🧩 데이터 수집
- **탄소배출량 데이터**
  - 전국 탄소 배출/흡수 통계
  - 출처 : 국토교통부 탄소공간지도 시스템
  - 지역별 환경 부담 수준을 나타내는 지표로 활용
  
- **호텔 활성화 데이터**
  - 출처 : 문화체육관광부 국민여행조사
  - 사용 변수
    - 여행지별 관광 숙박여행 재방문 의향
    - 1인 평균 여행지별 국내 숙박여행 지출액
    - 여행지별 국내 숙박 여행 횟수
    - 1인 평균 여행지별 국내 숙박여행 일수
    - 연간 총매출액(호텔)
  - 해당 변수들은 지역별 숙박 수요와 관광 소비 수준을 나타내는 지표로 사용
<br/>

## 🗂️ 데이터 전처리 및 최종 데이터셋
각 데이터는 시도 단위로 정리한 후 불필요한 변수 제거하여 데이터 단위로 정리했습니다.  
이후 시도명을 기준으로 데이터를 병합하여 최종 데이터셋을 구성했습니다.
  
```
시도명
+ 호텔 활성화 지표
+ 탄소배출량 지표
```
<br/>
